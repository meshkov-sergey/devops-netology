## Правила .gitignore для Terraform

В файле `terraform/.gitignore` используются следующие правила синтаксиса gitignore:

- **`/` в конце правила** — указывает, что правило относится только к директориям, но не к файлам.
Например, правило `.terraform/` игнорирует только директорию с именем `.terraform`, но не файл с таким именем.

- **`*` (звёздочка)** — заменяет любую последовательность символов (кроме `/`). Например:
  - `*.tfstate` — будут игнорироваться все файлы с расширением `.tfstate` (независимо от имени)
  - `*.tfstate.*` — будут игнорироваться все файлы, содержащие `.tfstate.` в имени (например, `prod.tfstate.backup`)
  - `crash.*.log` — будут игнорироваться файлы, начинающиеся с `crash.` и заканчивающиеся на `.log` (например, `crash.2024.log`)

- **`*` в середине имени** — заменяет любую последовательность символов внутри имени файла. Например:
  - `*_override.tf` — будут игнорироваться все файлы, заканчивающиеся на `_override.tf` (независимо от начала имени)

- **Конкретное имя файла без спецсимволов** — игнорируется только файл с точно таким именем. Например:
  - `crash.log` — игнорируется только файл с именем `crash.log`
  - `.terraformrc` — игнорируется только файл `.terraformrc`
  - `terraform.rc` — игнорируется только файл `terraform.rc`
  - `.terraform.tfstate.lock.info` — игнорируется только этот конкретный файл

- **`#` в начале строки** — комментарий, правило не применяется
